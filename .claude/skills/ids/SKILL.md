# IDS

1. **Identify:** Ask questions until the *root* issue is clear. State it in one sentence. Symptoms are not issues. Ask "why?" up to 3 times. Check `eos/l10/` recaps to see whether the issue has come up before.
2. **Discuss:** Lay out 2–3 options briefly, each with tradeoffs and a V/TO / Core Value check. No tangents.
3. **Solve:** Recommend one. Turn it into the right EOS tool:
   - Done in 7 days → **To-Do** (owner + date)
   - 90-day effort → **Rock** candidate
   - Recurring → **SOP** (`sops/`)
   - Needs a CEO decision → Leadership L10 issue
   - Not now → Long-Term Issues List
4. Record it in `eos/issues-list.md` and, if a decision was made, in `decisions/YYYY-MM-DD-<slug>.md`.
5. Don't create anything in ClickUp unless Betty asks. Say which ClickUp list it belongs in.
