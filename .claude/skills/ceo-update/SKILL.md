# CEO Update (Same Page)

One page, in this order:
1. **Scorecard:** trends in key ops measurables (`eos/scorecard.md` / ClickUp). Off-track items and the fix.
2. **Rocks:** on/off track.
3. **Wins:** from `growth/wins.md`, each tied to a Core Value or 3-Year Picture goal.
4. **Issues needing the Visionary:** only decisions the CEO can make.
5. **3-Year Picture pace:** `strategy/3-year-picture-tracker.md`.
6. **Next 30 days:** top 3.

Never invent numbers. Mark unknowns `[TBD]`. Save to `docs/ceo-updates/YYYY-MM-DD.md`.
