# Leadership Update

**Audience:** Lorna Neeley (COO, Integrator) is Betty's EOS lead. The CEO is the Visionary. Ask which audience and format if unclear:
- **Lorna 1:1 brief** (weekly): Ops Scorecard, Rocks, issues that need the Integrator, Betty's development ask
- **Monthly leadership / BOD update:** one page, sections below

## Sections (monthly)
1. **Ops Scorecard:** trends in key measurables (`eos/scorecard.md` / ClickUp). Off-track items and the fix.
2. **Rocks:** on/off track.
3. **Wins:** from `growth/wins.md`, tied to Core Values and the 3-Year Picture.
4. **Issues needing Lorna or the CEO:** only items above Betty's seat. Say whose call each one is.
5. **3-Year Picture pace:** `strategy/3-year-picture-tracker.md`.
6. **Next 30 days:** top 3.
7. *(Lorna brief only)* **Integrator development:** progress on `growth/integrator-development.md`.

Never invent numbers. Mark unknowns `[TBD]`. Save to `docs/leadership-updates/YYYY-MM-DD.md`.
