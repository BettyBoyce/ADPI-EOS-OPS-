# Log a Win

1. Capture: date, the win in one line, who.
2. Tag a **Core Value** (Positive, Relentless, Ownership, Invested, Impact) and the **3-Year Picture goal** it moves (revenue, profit, subscribers, mentors, lenders, or operational foundation).
3. Add evidence (link, metric, ClickUp task, Fathom moment).
4. Append a row to `growth/wins.md`.
5. If it's a team member's win, add it to their `team/` file and suggest recognizing it in the L10 Segue or Headlines.
